## Adversarial Testing Notes

**Expected Outcome**: We EXPECT to find bugs during this testing. This is the point of adversarial testing.

**Process When Bug Found**:
1. **Stop** - Do not continue to next test
2. **Document** - Add bug to this file using template above
3. **Investigate** - Determine root cause (code location, logic error)
4. **Fix** - Apply fix in ~/Code/spec-kitty repository
5. **Verify** - Re-run test, ensure passes
6. **Continue** - Move to next test

**Severity Guidelines**:
- **CRITICAL**: Data corruption, security vulnerability, total feature failure
- **HIGH**: Feature broken, workflow blocked, user-facing failure
- **MEDIUM**: Degraded experience, confusing errors, workarounds exist
- **LOW**: Minor issues, cosmetic problems, edge case handling
