### Bug #1: Sparse-Checkout Not Enforced - Manual kitty-specs/ Can Be Tracked

**Test**: test_manual_kitty_specs_creation_ignored
**Severity**: CRITICAL (data corruption risk, state divergence)
**Track**: Sparse-checkout infrastructure
**Found**: 2026-01-14
**Fixed**: Not yet fixed

**Symptoms**:
- User manually creates kitty-specs/ directory in worktree
- User can `git add kitty-specs/test.md`
- File shows in `git status --porcelain` as `?? kitty-specs/test.md`
- Sparse-checkout patterns NOT preventing tracking

**Root Cause**:
- Sparse-checkout patterns in .git/info/sparse-checkout not being enforced
- Pattern `!/kitty-specs/**` should prevent ANY files in kitty-specs/ from being tracked
- Git is ignoring sparse-checkout configuration or patterns incorrect

**Expected Behavior**:
- `git add kitty-specs/test.md` should be silently ignored
- `git status` should NOT show kitty-specs/ files (excluded by sparse-checkout)
- `git ls-files kitty-specs/` should return empty

**Actual Behavior**:
- Files CAN be added to git in worktree
- git status DOES show kitty-specs/ files
- Sparse-checkout not preventing user from committing worktree-local status

**Impact**:
- CRITICAL: Users could accidentally commit worktree-local kitty-specs/ changes to main branch
- This defeats the entire purpose of sparse-checkout (preventing state divergence)
- Multiple agents would have conflicting status files committed to main

**Fix Needed**:
- Location: ~/Code/spec-kitty/src/specify_cli/cli/commands/implement.py lines 596-642
- Investigate: Why sparse-checkout patterns not enforced?
- Validate: Test git config core.sparseCheckout, core.sparseCheckoutCone settings
- Validate: Test sparse-checkout file patterns format
- Consider: Maybe need `git sparse-checkout set` instead of manual file writing?

**Verification**:
- Test should pass after fix
- Manual `git add kitty-specs/` in worktree should be ignored
- Additional validation: Run `git sparse-checkout list` in worktree, verify patterns correct

**Files to Investigate**:
- ~/Code/spec-kitty/src/specify_cli/cli/commands/implement.py:596-642
- Check: How sparse-checkout file is written
- Check: How patterns are applied (git read-tree vs git sparse-checkout commands)
